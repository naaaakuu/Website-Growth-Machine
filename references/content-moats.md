# Content Moats

Load before a significant content program, programmatic page expansion, calculator, directory, comparison engine, or research asset.

## Core question

Ask: “What could we create that competitors cannot cheaply reproduce, and why would the intended customer use it?” Articles are only one possible form.

Candidate defensible assets include original datasets, surveys, benchmarks, calculators, decision tools, transparent methodologies, searchable directories, pricing databases, expert interviews, permissioned case studies, templates, comparison engines, diagnostic workflows safe for the domain, original media, and maintained reference material.

## Asset decision

Score usefulness, uniqueness, credibility, commercial connection, citation/distribution potential, cost, maintainability, update risk, defensibility, and accessibility. Define inputs, outputs, assumptions, limitations, data provenance, error states, reviewer, update cadence, owner, and success evidence.

Reject an asset that cannot be kept truthful or useful. “Generate hundreds of generic pages” is not a default moat strategy. Avoid deceptive scoring systems, unsupported recommendations, and unreviewed consequential advice.

## Build and learn

Start with a narrow asset that completes a user task. Instrument use and downstream outcomes appropriately. Record whether use, trust, distribution, conversion, maintenance burden, and repeat use actually change. Expand only after evidence or explicit strategic justification.
